## Codebase Patterns

- **build-release.sh codesign**: after `bun build --compile`, always re-sign ad-hoc with `codesign --force --sign - "${BIN}"` and verify with `codesign -v "${BIN}"`. Without re-sign the binary has an invalid signature and amfid SIGKILL-kills it when installed in /usr/local/bin.
- **build-release.sh --install**: copies dist/cam-darwin-arm64 to `${HOME}/.local/bin/cam` (user-owned, no sudo), strips quarantine with `xattr -cr`, re-signs ad-hoc, smoke-tests `--version`, warns if dest dir is not on $PATH. Use `case ":${PATH}:" in *":${DIR}:"*) ...` for POSIX-safe PATH membership check. Arg parsing uses `while [[ $# -gt 0 ]]; do case "$1"` loop so `--install` can consume an optional positional `$2` via `shift`.
